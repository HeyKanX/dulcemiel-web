## Hallazgos críticos y lectura del gate

El build quedó fallido por `TC-NF-INT-002` en Behave/Selenium, 3 fallos de casos Playwright (`TC-NF-ACC-004`, `008`, `009`) y fallos axe-core de accesibilidad. La causa en `TC-NF-INT-002` no está confirmada: el navegador no mostró “Miel QA” tras recargar, mientras una consulta API separada sí devolvió HTTP 200 y encontró el producto. Los casos de accesibilidad fueron observados con evidencias del build y están asociados a cuatro defectos triados. El gate fallido conserva esos problemas visibles y no bloqueó la generación de las demás métricas.

El artefacto visual actualizado está en [metricas-calidad-build-16.html](metricas-calidad-build-16.html); el resumen estructurado que lo sustenta está en [quality-summary-build-16.json](quality-summary-build-16.json). El informe por suite y la explicación detallada están en [CI-BUILD-16-METRICAS-2026-11-13.md](../fase-3/CI-BUILD-16-METRICAS-2026-11-13.md).
