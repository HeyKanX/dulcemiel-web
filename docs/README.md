# Iniciar Dulce Miel y sus pruebas

1. En la raíz del repositorio, sigue `README.md` para configurar SQL Server, iniciar `backend/` y levantar `frontend/`.
2. Comprueba `http://localhost:5000/api/health` y abre `http://localhost:4200`.
3. Para preparar la base aislada de QA y ejecutar cada suite, sigue `qa/README.md`.

Los comandos rápidos del programa también están en `docs/QUICK_START.md`. El diseño de casos, las ejecuciones y los resultados de la auditoría están en el informe del proyecto, dentro de la carpeta `Informe`.
